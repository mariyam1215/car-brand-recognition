Dataset & code

Dataset: Stanford Cars

Secondary dataset (Krause et al., 3dRR 2013): {{N_IMAGES}} photos of cars labelled with make, model and year (196 classes). We keep only the make, which turns it into a {{N_BRANDS}}-brand recognition task.

Model

Transfer learning: an EfficientNetV2-B0 network pre-trained on ImageNet already knows edges, shapes and textures. We teach it to tell car brands apart in two stages.

Photosquashed to 224 × 224 RGB
EfficientNetV2-B0ImageNet weights, 5.9M parameters
Global average pool1280 features
Dropout 0.3 + Densesoftmax over {{N_BRANDS}} brands

Stage 1: linear probe

Backbone frozen, only the final layer is trained on its features. Quick baseline: {{PROBE_TOP1}} test accuracy.

Stage 2: fine-tuning

Upper blocks unfrozen ({{TRAINABLE}} layers) and trained for {{EPOCHS}} epochs with augmentation. Final: {{TOP1}}.

Training details

OptimiserAdamW, weight decay 1e-4, peak learning rate 2e-4, 1 warm-up epoch then cosine decay
LossCross-entropy with label smoothing 0.1; class weights ∝ (median count / count)0.5 to soften imbalance
Augmentationhorizontal flip, rotation ±4%, shift 8%, zoom, brightness, contrast
Batch size / epochs32 / {{EPOCHS}} (best epoch chosen on validation accuracy)
HardwareCPU only (4 cores)
Deployed modelONNX, {{ONNX_MB}} MB, takes raw 0-255 pixels, no extra preprocessing

Limitations

  • Brand-level labels come from the make of 196 specific models; several brands are represented by a single model (for example Tesla Model S 2012), so other models of that brand may be missed.
  • Most photos show cars from 2000-2012. New designs and heavy modifications are out of distribution.
  • The model has no "not a car" or "unknown brand" class; it always names one of the {{N_BRANDS}} brands, so low confidence is the signal to distrust it.
